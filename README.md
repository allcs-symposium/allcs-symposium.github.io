# ALLCS 研究集会 Webサイト管理マニュアル

本リポジトリは、研究集会「Algebra, Logic and Languages in Computer Science」の公式Webサイト（GitHub Pages）です。

## 新年度のページ作成手順（ブラウザのみで作業可能）

1. 本リポジトリの `2027` フォルダを参考に、新しい年度のフォルダ（例: `2028`）を作成します。
2. フォルダ内に `index.md` を作成し、開催日程・会場・プログラム等を記述します。
3. ルートにある `index.md`（ポータルTOP）に、新しい年度へのリンクを追加します。
4. ファイル編集画面下の **[Commit changes...]** を押すと、数分以内に公開Webサイトへ反映されます。

## PDFファイル等のアップロード
プログラムのPDFなどは、各年度フォルダ内の `files/` に直接ドラッグ＆ドロップで追加し、Markdown内からリンク（`[予稿集](./files/program.pdf)`）を貼ってください。
