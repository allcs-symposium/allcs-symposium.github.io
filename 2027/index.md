## 講演募集・参加登録 / Call for Papers & Registration

本研究集会では、理論計算機科学、数理論理学、代数系、言語理論、およびその周辺分野に関する講演を広く募集いたします。

We invite submissions for presentation on all aspects of theoretical computer science, mathematical logic, algebraic systems, formal language theory, and related fields.

* **申込締切 / Application Deadline**: 令和8年12月28日（月）23:59（日本時間） / Dec 28 (Mon), 2026, 23:59 JST
* **申込フォーム / Registration Forms**:
  * [日本語フォーム](https://docs.google.com/forms/d/e/1FAIpQLScAIoldyfsDoApkpTKFLv87LvRoLj6JGM6PgLlP-5A-pve-NA/viewform)
  * [English form](https://docs.google.com/forms/d/e/1FAIpQLSeKo_a6giA1hEJ0dxnUjHsGsetTtWEo-a-uuEcEzdpAe49xOw/viewform)

> **旅費支援について / Travel Support:**  
> 若手研究者・大学院生等を優先とし、予算の範囲内で旅費の支給が可能です。ご希望の方は講演申込フォームにてお知らせください。  
> Financial support for travel expenses is available for a limited number of participants (priority given to early-career researchers and students). Please request support via the registration form.
